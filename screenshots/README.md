# Скриншоты

## Работа в Django shell

- `shell_create.png` — создание категорий и продуктов через ORM-запрос `create()`
  в Django shell.
- `shell_queries.png` — получение всех категорий и продуктов, фильтрация продуктов
  по категории, обновление цены и удаление продукта.

Команды выполнялись в интерактивной консоли:

```bash
python manage.py shell
```

## Страницы сайта

- `home_page.png` — главная страница со списком товаров из базы данных.
- `product_detail.png` — страница товара с описанием, ценой и изображением.
- `product_form.png` — форма добавления товара.
